# Accessibility Features

The game incorporates accessibility considerations to improve usability and inclusivity across a range of player needs:

- High contrast user interface elements to improve readability and visibility for players with low vision
- Colour-blind friendly design that does not rely solely on colour to communicate feedback or status — icons and text labels accompany all colour indicators
- All educational feedback and scenario text is presented in clear, readable font sizes with adequate spacing
- Subtitles and full text descriptions are provided for all audio elements, ensuring the game is fully playable without sound
- Adjustable audio controls allowing players to independently modify or mute music and sound effects
- Mouse click and touchscreen tap controls requiring minimal input complexity, supporting players with limited motor ability
- Pause functionality available at any point during gameplay to support players who need additional processing time
- No time pressure during scenario reading — the timer only begins after the player has finished reading and selects an answer
- Hint system provides an additional support layer for players who find questions challenging, reducing frustration and supporting continued engagement
- Clear visual feedback confirming when an answer has been selected before submission
- Simple, consistent navigation layout maintained across all stages to reduce cognitive load
- Language used throughout the game has been kept clear and accessible, avoiding jargon and complex sentence structures

These accessibility considerations aim to reduce barriers and create a more inclusive learning environment, ensuring the game is usable and beneficial for the widest possible range of players within the target demographic.
